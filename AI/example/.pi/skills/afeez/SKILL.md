# afeez — R EDA Notebook Generator

## Purpose

`afeez` generates a complete Jupyter notebook (`.ipynb` with an **R kernel**) that performs full exploratory data analysis. It enforces:
- **Notebook output** — every analysis step is a structured cell (markdown + code).
- **`theme_minimal()` on all plots** — clean, modern ggplot2 styling.
- **`gtsummary` tables** — normality-aware formatting and p-values.
- **Smart test selection** — parametric (t-test / ANOVA) vs. non-parametric (Wilcoxon / Kruskal-Wallis) based on Shapiro-Wilk normality checks.
- **User-directed scope** — before running, afeez asks the user which variables, the outcome, and any row-level constraints.

## When to use
- User says: `afeez`, `do EDA`, `univariate analysis`, `bivariate analysis`, `compare [outcome] with...`
- The dataset is already loaded or a file path is provided.
- Output should be a reusable, shareable `.ipynb` notebook.

## Workflow

### Step 1 — Gather user intent (ask before proceeding)

Before generating any code, ask the user the following three questions:

1. **Narrow or full analysis?**
   > "Do you want to analyze **all variables** in the dataset, or would you like to select a subset of variables?"
   - If subset: ask which columns they want included (by name).
   - Always ask them to name the **outcome/target variable** if one exists.

2. **Outcome variable**
   > "What is your **outcome variable** (the grouping/target variable for bivariate analysis)? If none, I will produce only univariate analysis."

3. **Constraints / filtering**
   > "Do you want to apply any **filtering constraints** (e.g., `Age >= 18`, `Gender == "female"`, exclude missing outcomes)?"
   - Let the user specify any number of `dplyr::filter()` conditions.
   - Default if none: no filtering (but exclude rows where the outcome is `NA` if doing bivariate analysis).

Record their answers and use them to parameterise the notebook.

num_vars <- names(df_filtered)[sapply(df_filtered, is.numeric)]

    pval <- NA

#### Cell 8 — Code: Normality-Aware gtsummary Table

```r
build_stat_list <- function(data, outcome) {
  num_vars <- setdiff(names(data)[sapply(data, is.numeric)], outcome)
  lst <- list()
  for (v in num_vars) {
    vals <- na.omit(data[[v]])
    n <- length(vals)
    if (n >= 3 && n <= 5000) {
      is_norm <- stats::shapiro.test(vals)$p.value > 0.05
    } else {
      is_norm <- FALSE
    }
    lst[[v]] <- if (is_norm) "{mean} ({sd})" else "{median} ({p25}, {p75})"
  }
  lst
}

build_test_list <- function(data, outcome) {
  num_vars <- setdiff(names(data)[sapply(data, is.numeric)], outcome)
  cat_vars <- setdiff(names(data)[sapply(data, function(x) is.factor(x) || is.character(x))], outcome)
  lst <- list()
  n_out <- nlevels(data[[outcome]])
  for (v in num_vars) {
    vals <- na.omit(data[[v]])
    n <- length(vals)
    if (n >= 3 && n <= 5000) {
      is_norm <- stats::shapiro.test(vals)$p.value > 0.05
    } else {
      is_norm <- FALSE
    }
    lst[[v]] <- if (is_norm) {
      if (n_out == 2) "t.test" else "aov"
    } else {
      if (n_out == 2) "wilcox.test" else "kruskal.test"
    }
  }
  for (v in cat_vars) {
    tab <- table(data[[v]], data[[outcome]], useNA = "ifany")
    if (any(stats::chisq.test(tab)$expected < 5, na.rm = TRUE)) {
      lst[[v]] <- "fisher.test"
    } else {
      lst[[v]] <- "chisq.test"
    }
  }
  # convert to formula list
  purrr::imap(lst, function(t, v) {
    rlang::new_formula(rlang::sym(v), rlang::sym(t))
  })
}

stat_list <- build_stat_list(df_filtered, "{outcome}")
test_forms <- build_test_list(df_filtered, "{outcome}")

bivariate_tbl <- df_filtered %>%
  gtsummary::tbl_summary(
    by = "{outcome}",
    statistic = stat_list,
    missing = "ifany",
    missing_text = "Missing"
  ) %>%
  gtsummary::add_overall() %>%
  gtsummary::add_p(test = test_forms) %>%
  gtsummary::bold_labels()

bivariate_tbl
```

## Rules for the Agent
1. **Never proceed without the 3 questions answered.**
2. All plot code must end with `+ theme_minimal()`.
3. The notebook kernel **must** be `"ir"` (R kernel).
4. Use `readr::read_csv` for loading data; be explicit about `na = c("", "NA", "N/A", ".")`.
5. Shapiro-Wilk threshold: `p > 0.05` = normal.
6. Numeric variable with `n < 3` or `n > 5000` → treat as **non-normal** (no Shapiro, default to median + non-parametric test).
7. `gtsummary` test formulas should be built programmatically so each variable gets its own test based on normality.
8. If the user declines an outcome variable, skip Cells 7–9 (bivariate section) entirely.
9. Save the `.ipynb` in the working directory with a descriptive name, e.g., `{dataset}_eda.ipynb`. Confirm the save path with the user.
